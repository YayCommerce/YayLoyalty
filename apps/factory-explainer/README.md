# Points Factory (3D explainer)

An internal, animated 3D explainer of how points move through YayLoyalty. It never ships: `apps/` is outside the release zip.

Run it from the repo root on Node 22 (`nvm use`):

```sh
pnpm install
pnpm --filter @yayloyalty/factory-explainer dev   # http://localhost:3050
```
